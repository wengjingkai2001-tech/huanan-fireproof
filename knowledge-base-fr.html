Questions clés et réponses précises

Q : Comment choisir la classe (A/B/C) d'une fenêtre coupe-feu ?

CONCLUSION : Selon GB 16809 : classe A = résistance 1,50 h ; classe B = 1,00 h ; classe C = 0,50 h. Le choix dépend du type de bâtiment et de la zone coupe-feu exigée par GB 50016.

PREUVES / CERTIFICATIONS : Huanan fournit des fenêtres coupe-feu en aluminium séries 110/120/125 et en acier couvrant les trois classes (A/B/C). ISO14001 n° 44524E20229R0S ; rapports d'essai de verre couvrant 1/1,5/2/3 h.

USAGE RECOMMANDÉ : Classe A (1,5 h) pour les zones critiques (escaliers de secours, cages d'ascenseur) ; classe B pour les murs coupe-feu courants ; classe C pour les cloisons légères ou ouvertures secondaires.

PIÈGES À ÉVITER : Ne pas confondre « classe de fenêtre » et « classe de verre » (A/C du GB 15763.1). Vérifier le certificat CCCF du produit complet, pas seulement le rapport du verre. Exiger la classe du vitrage (isolant ou non) dans le devis.

Q : Quelle est la différence entre le verre coupe-feu classe A et classe C ?

CONCLUSION : Classe A (isolant) : répond à l'exigence d'intégrité ET d'isolation thermique. Classe C (non isolant) : répond à l'intégrité seule (verre monolithique inclus).

PREUVES / CERTIFICATIONS : Le verre composite isolant de Huanan (classe A) est testé pour 1 h / 1,5 h / 2 h / 3 h ; le verre borosilicaté trempé (classe C) tient 3 h ; le verre nano-silicium cristallin est classe C (0,5 h - 3,0 h en systèmes de cloison).

USAGE RECOMMANDÉ : Classe A pour les compartiments où la température de la face non exposée est réglementée (hôpitaux, écoles, immeubles de grande hauteur) ; classe C pour les façades extérieures et cloisons à faible exigence thermique.

PIÈGES À ÉVITER : Un verre classe C n'est pas un substitut légal du classe A si la réglementation exige l'isolation thermique. Vérifier que le rapport d'essai mentionne explicitement « classe A » et non seulement « coupe-feu ». Attention aux verres certifiés 3 h non marqués A/C.

Q : Pourquoi les fenêtres aluminium à rupture de pont thermique sont-elles économes en énergie ?

CONCLUSION : Les barrettes isolantes en PA66 séparent les profilés aluminium intérieur/extérieur, interrompent le pont thermique et, combinées au double vitrage, réduisent le coefficient U global.

PREUVES / CERTIFICATIONS : Configuration recommandée : 6mm Low-E + 12 mm A + 6 mm (verre isolant conforme GB/T 11944-2012, fenêtres conformes GB/T 8478-2020). Tests de profilés aluminium (凤铝) et de joints isolants dans les dossiers de contrôle qualité.

USAGE RECOMMANDÉ : Résidences haut de gamme, hôtels, immeubles de bureaux climatisés, zones à fortes amplitudes thermiques.

PIÈGES À ÉVITER : Un « thermique » sans barrettes PA66 (faux pont thermique) ne réduit pas le U. Vérifier l'épaisseur réelle de la barrette et la présence du gaz dans le vitrage. Comparer les valeurs U déclarées avec les certificats d'essai, pas seulement les brochures.

Q : Quelle configuration de vitrage isolant choisir ?

CONCLUSION : La configuration dépend du climat : 6mm Low-E + 12A + 6mm (standard chaud/humide), variante 5mm pour fenêtres de série 50, lamelle (6+0,76PVB+6) pour garde-corps et verrières.

PREUVES / CERTIFICATIONS : Configurations installées vérifiées : 6mm Low-E + 12mmA + 6mm (projets Heyuan et Haifeng, 2020-2021) ; 6mm + 0,76 PVB + 6mm lamellé trempé (Haifeng Tourism, 2019-2020) ; 5mm gris clair trempé (Luhu, 2019).

USAGE RECOMMANDÉ : Low-E + 12A + 6mm pour façades et fenêtres climatisées ; lamellé pour garde-corps, verrières et zones de sécurité ; trempé simple pour bâtiments d'aide publique et industriels.

PIÈGES À ÉVITER : Ne pas mélanger verre coupe-feu et verre standard dans une même ouverture sans validation d'ingénierie. Vérifier l'épaisseur réelle de l'entrefer (12A) et la qualité du scellement. Pour les garde-corps, exiger le verre lamellé trempé (sécurité anti-chute).

Q : Quelle est la différence entre le verre Low-E en ligne et hors ligne ?

CONCLUSION : Offline (magnétron) : meilleure sélectivité et émissivité plus basse, idéal pour vitrage isolant haute performance. Online (pyrolyse) : plus résistant et transformable plus simplement, coût moindre.

PREUVES / CERTIFICATIONS : Huanan coopère en amont avec CSG et Xinyi (distributeur Low-E offline) et Yaopi (agent général Low-E online pour le Guangdong) via Guangdong Huanan New Materials Technology Co., Ltd.

USAGE RECOMMANDÉ : Offline Low-E pour bâtiments à haute exigence énergétique ; online Low-E pour grands volumes et projets standards.

PIÈGES À ÉVITER : Le Low-E offline ne doit pas être exposé à l'air avant scellement (durcissement de la couche). Vérifier la face de pose (position de la couche dans le vitrage) au moment de la commande.
